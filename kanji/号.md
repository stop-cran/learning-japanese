# 号 — number; call

**Strokes:** 5 · **Key (radical):** 口 (no. 30) · **Phonetic:** not identified here · **JLPT:** N3 (community list)

## Meaning and origin

号 can mark a number, name, or designation; it also has a calling sense.
[番号](../words/番号.md) ばんごう is a useful starting word: a number used to identify something.

**Modern-shape mnemonic:** imagine the 口 box calling out an identifying number above the bent lower stroke.
This is a visual story for memory, not etymology.

## Common words

- [番号](../words/番号.md) ばんごう — number; identifying digits
- 信号 しんごう — signal; traffic light
- 電話番号 でんわばんごう — telephone number

## Notes

A number in 番号 labels something; it need not count a quantity.
In [台](台.md) the 口 is at the bottom, while in 号 it is at the top.
[古](古.md) likewise has its box below another element.
The kun readings remain in metadata; this introductory table concentrates on ゴウ compounds.
