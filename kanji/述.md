# 述 — state; relate

**Strokes:** 8 · **Key (radical):** 辵 (no. 162) · **JLPT:** N2 (community list)

## Meaning and origin

述 concerns stating or relating something in words. 述べる means to state or express, while 記述 is a written description or account.

**Modern-shape mnemonic, not etymology:** See the 辶-shaped part carrying the 朮-shaped inner block along like an account being delivered. This is a visual memory story, not an etymological or phonetic claim.

The canonical indexing radical 辵 appears in its shortened form 辶.
