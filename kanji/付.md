# 付 — attach

**Strokes:** 5 · **Key (radical):** 人 (as 亻, no. 9) · **JLPT:** N3 (community list)

## Meaning and origin

付 is useful for attachment: one thing is joined to another.
[付ける](../words/付ける.md) つける describes attaching something, while 付く つく describes something becoming or being attached.
The difference matters even when English can use "stick" for both.

**Modern-shape mnemonic:** imagine the small dot beside the hooked right-hand stroke as a label being fixed in place.
This is a memory device, not a claim about the original components.
