# 栞 — bookmark; guidebook

**Strokes:** 10 · **Key (radical):** 木 (no. 75) · **JLPT:** N1 (community list)

## Meaning and origin

栞 is useful for recognizing **しおり**, a **bookmark** or a **guidebook**. The linked [栞](../words/栞.md) article distinguishes the object that marks a page from a booklet that guides someone.

**Modern-shape mnemonic, not etymology:** Find 木 at the bottom and imagine the upper strokes as markers pointing to a route or page. This is a visual memory aid, not a historical derivation.

## Notes

- The kana spelling しおり is useful even when learning to recognize 栞. Recognition of this character does not require using the kanji every time.
- [刊](刊.md), publish or issue, has 刂 on the right rather than 木 below. [床](床.md), floor or bed, has 广 above 木; [未](未.md), not yet, has a much simpler outline.
- A personal name written 栞 need not be interpreted by guessing from this table. Name readings are outside this card's scope.
