# 頼 — request; rely

**Strokes:** 16 · **Key (radical):** 頁 (no. 181) · **JLPT:** N3 (community list)

## Meaning and origin

頼 connects asking for help with reliance on someone. [頼む](../words/頼む.md) たのむ is to request;
頼る (たよる) is to rely on. A request is an action, whereas reliance can describe an ongoing relationship.
Learn the different endings as part of the verbs.

**Modern-shape mnemonic:** picture the [束](束.md) shape on the left as a bundle you ask someone beside you to carry.
The right block is 頁. This is a memory aid, not a historical origin story.

## Notes

頼む is not a replacement for [質問](../words/質問.md) しつもん, "question": asking for an action differs
from asking for information.
Meaning alone may not distinguish 頼 from [願](願.md), which also has a request sense.
Compare the left components of [頭](頭.md), [題](題.md), and [類](類.md) instead.
