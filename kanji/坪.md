# 坪 — tsubo; area unit

**Strokes:** 8 · **Key (radical):** 土 (no. 32) · **JLPT:** N1 (community list)

## Meaning and origin

坪 (つぼ) is a traditional area unit used for land and buildings. One 坪 is about 3.3 square metres. This card focuses on that area sense; the same written form has other dictionary senses.

**Modern-shape mnemonic, not etymology:** connect 土, “ground,” with an imagined measured plot. This is a memory aid, not a historical explanation.
