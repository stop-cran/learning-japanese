# 過 — exceed; go beyond

**Strokes:** 12 · **Key (radical):** 辵 (as 辶, no. 162) · **Phonetic:** not identified here · **JLPT:** N3 (community list)

## Meaning and origin

過 is useful for passing beyond a point or exceeding an amount. [過ぎる](../words/過ぎる.md) すぎる can mean passing a place or the passage of time.
過去 かこ names the past, while 過ごす すごす describes spending time.

**Modern-shape mnemonic:** treat the box-like center as a marker that the sweeping 辶 path goes past.
This is a visual memory aid, not an origin story.

## Notes

The excessive-use suffix is usually written in kana: 食べすぎる (たべすぎる), "eat too much."
It attaches to the verb's ます-stem: 食べます → 食べ + すぎる.
Compare the box-like center of 過 with 周 inside [週](週.md); they are not the same component.
