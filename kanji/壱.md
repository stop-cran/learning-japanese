# 壱 — one in formal documents

**Strokes:** 7 · **Key (radical):** 士 (no. 33) · **JLPT:** N1 (community list)

## Meaning and origin

壱 writes the number one in formal contexts such as amounts on documents. It is a different way to write the same number as 一, not a different counting system.

**Shape mnemonic, not etymology:** The top resembles 士 and there is a cover over the lower part. Compare [売](売.md) (sell): look below the cover before deciding which character you saw.

## Common words

## Notes

For routine counting, use [一](一.md). 壱万円 (いちまんえん) and 一万円 give the same amount. The more elaborate first character does not add a zero.

Compare the lower halves of [売](売.md) (sell), [吉](吉.md) (good fortune), and [声](声.md) (voice): none ends in the 匕 shape below 壱's cover.
