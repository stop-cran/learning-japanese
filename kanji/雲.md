# 雲 — cloud

**Strokes:** 12 · **Key (radical):** 雨 (no. 173) · **JLPT:** N2 (community list)

## Meaning and origin

雲 concerns clouds. 暗雲 names dark clouds and can also describe ominous indications; 雨雲 is a rain cloud.

**Modern-shape mnemonic, not etymology:** Imagine the 雨-shaped top above a 云-shaped cloud curling below it. This is a visual memory story, not etymology.

The canonical radical 雨, no. 173, occupies the top.
