# 加 — add

**Strokes:** 5 · **Key (radical):** 力 (no. 19) · **JLPT:** N3 (community list)

## Meaning and origin

加 concerns adding something or joining what is already there. In [参加](../words/参加.md) さんか,
the addition is a participant, not a number in arithmetic.

**Modern-shape mnemonic:** picture adding the right-hand 口 box beside 力. This is a memory aid, not an origin account.

- 加わる くわわる — join; be added

## Notes

水を加える (みずをくわえる) means "add water": the added thing takes を.
In contrast, 加わる describes something joining or being added.
[助](助.md) also contains 力, but places it on the right rather than the left.
