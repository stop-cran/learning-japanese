# 職 — employment; post

**Strokes:** 18 · **Key (radical):** 耳 (no. 128) · **JLPT:** N3 (community list)

## Meaning and origin

職 concerns employment, an occupation, or a post someone holds.
[職業](../words/職業.md) しょくぎょう names an occupation; 就職 しゅうしょく
concerns getting a job. The character points toward working roles, not every possible task.

**Modern-shape mnemonic:** locate 耳 on the left, then the 音-like block and crossing strokes
on the right, like a crowded workplace chart. This is only a modern memory aid.

## Notes

The source also records ソク; the examples here use ショク.
[耳](耳.md), [聞](聞.md), and [音](音.md) are useful component comparisons, but
their meanings are not employment.
In 職場, 場 is read ば: learn しょくば as the complete word.
