# Japanese requests, permission, and rules

"Please do it," "you may do it," "do not do it," and "you must do it" are different messages.
Learn the whole ending rather than treating every negative-looking piece as a prohibition.

## Four useful messages

| Function | Example | Meaning |
| --- | --- | --- |
| Request an action | ここに名前を書いてください。 | Please write your name here. |
| Request that someone refrain | ここには名前を書かないでください。 | Please do not write your name here. |
| Permit an action | ここに名前を書いてもいいです。 | You may write your name here. |
| Prohibit an action | ここに名前を書いてはいけません。 | You must not write your name here. |

Read **名前（なまえ）** and **書く（かく）**.
A polite request can still sound direct or carry authority in context. ください is not a guarantee that
any demand becomes socially appropriate; more indirect requests can be useful later.
The [respectful/humble introduction](honorifics-humble-and-polite-language.md#courteous-requests-who-will-do-the-action)
adds compact お／ご requests and ていただけませんか, separating the listener's action from the speaker's
receiving viewpoint. Those are a later, separately owned practice scope, not extra answers required here.

## Requests: affirmative て, negative ないで

Use **て-form + ください**, including a で-form where the verb requires it:
読んでください（よんでください）, "please read."
For the ordinary negative request, use **ない-form + でください**:
読まないでください, "please do not read."

Do not mechanically turn the negative request into 読まなくてください.
The [verb tables](japanese-verb-foundations.md) supply 読んで and 読まない.
The separate **ないで**, "without doing," is a later construction, not a reason to confuse the request's form.
For bare て／ないで requests and questions such as 読んでくれない？ versus 読まないでくれない？,
continue to [doing things for others and asking favors](benefactive-actions.md).
The negative on a favor-question auxiliary does not by itself negate the requested action.

## Permission: it is acceptable, not compulsory

> この椅子に座ってもいいですか。  
> このいすにすわってもいいですか。  
> May I sit in this chair?

In a permission question, **～てもいいですか** asks whether the action is acceptable.
An affirmative answer permits it; it does not command the person to sit.

The same basic acceptability pattern can follow adjectives and nouns:

| Starting predicate | Acceptable condition |
| --- | --- |
| 安い（やすい）, inexpensive | 安くてもいい, it is fine if it is inexpensive |
| 静か（しずか）, quiet | 静かでもいい, it is fine if it is quiet |
| 鉛筆（えんぴつ）, pencil | 鉛筆でもいい, a pencil is acceptable too |

For い-adjectives, use **くてもいい**; for nouns and な-adjectives, **でもいい**.
This でも construction is not automatically the same task as the more advanced "even" or example-suggestion
uses in [restriction and inclusion](only-and-unexpected-inclusion.md).

## Prohibition and obligation: track both negatives

| Pattern | Basic message |
| --- | --- |
| 読んではいけない | Must not read. |
| 読まなくてはいけない | Must read: not reading is unacceptable. |
| 読まなくてはならない | Must read, with a more formal-sounding alternative ending in many contexts. |

The negative **ない** inside 読まなくてはいけない reverses what is being ruled out.
Do not translate it as "must not read" merely because the sentence contains negative pieces.
Polite endings include **いけません／なりません**.
These forms have register tendencies, not a rigid rule that one can never be spoken.

For the negative obligation form, first build 読まない, then change ない to **なくては** and add the ending.
An instruction to read is different from merely permitting reading, and from advising that reading would be useful.

## Common conversational contractions

| Full construction | Common shorter form | Meaning |
| --- | --- | --- |
| 読んではいけない | 読んじゃいけない | must not read |
| 食べてはいけない | 食べちゃいけない | must not eat |
| 読まなくてはいけない | 読まなくちゃ（いけない） | have to read |
| 読まなければならない | 読まなきゃ（ならない） | have to read |

**なくちゃ** contracts **なくては**; **なきゃ** contracts **なければ**.
They are not two contractions of the same written sequence.
The omitted ending is often understood in ordinary conversation. This is recognition of a common obligation
pattern, not a claim that every conditional fragment ending in なくちゃ or なきゃ independently expresses obligation.

The short **dictionary verb + な** in a warning, such as **入るな（はいるな）**, "Do not enter,"
is a strong prohibition. It is not the same as inviting someone to do something gently, and it is not a
replacement for ないでください in every relationship. Initial practice treats it as register-sensitive recognition.

## Advice is not a rule

**早く寝たほうがいいですよ**（はやくねたほうがいいですよ） recommends going to bed early.
It does not by itself establish a rule that the listener must obey.
The existing [positive and negative advice lesson](koto-wake-and-formal-nouns.md#ほうがいい-recommend-doing-or-not-doing)
already practises ～たほうがいい／～ないほうがいい; use that material rather than memorize a second set of identical cards.

The later **～なくてもいい** means an action is not required; that is not a prohibition.
Continue with [necessity, advice and instructions](necessity-advice-and-instructions.md) for focused
N4 practice of that distinction, necessity and obligation forms, commands, suggestions, regrets and relief.
It reuses the introductory requests/rules here rather than replacing their exercises.
The advanced [no-need comparison](koto-wake-and-formal-nouns.md#ほか-exclusion-and-no-other-option)
also distinguishes unnecessary from impossible or unavailable.
These are onward links, not hidden requirements of the introductory scored exercises here.

## Practice and sources

Formation tasks state their requested ending family and accept suitable alternative endings within that task.
Interpretation tasks classify supplied utterances and their register. These are scaffolded formation and recognition,
not a claim that the learner has independently selected a message in an unprompted conversation.
Several real-world utterances can achieve a similar request; no isolated sentence proves one universally
best degree of politeness.
