# Content format (schema version 1, draft)

The Android app [kanji-cards-android](https://github.com/stop-cran/kanji-cards-android) reads this repository. Anyone can fork it and
point the app at their fork. The rules below are checked by `tools/validate.py`.

```
manifest.json          generated by tools/build_manifest.py: schemaVersion, contentVersion, SHA-256 per file
kanji/<char>.md        one card per kanji, e.g. kanji/日.md
words/<word>.md        one article per word, e.g. words/大小.md
articles/<slug>.md     free-form articles (no front matter required)
strokes/<char>.json    generated by tools/generate_strokes.py from KanjiVG
```

## Kanji card

YAML front matter followed by the Markdown article.

| Field | Meaning |
| --- | --- |
| `kanji` | The character; must equal the file name. This is the card's stable ID. |
| `title` | Short English meaning shown in the question state; unique across cards. |
| `jlpt` | 1–5 (N5 is easiest). JLPT published no official kanji lists after 2010, so this follows the community lists as mirrored by kanjiapi.dev (79 kanji at N5). The deck is a words-driven starter set with kanji of all levels; kanji outside N5 are included because the starter words need them. |
| `tags` | Free tags, e.g. `jlpt-n5` (must match `jlpt`), `starter` (all cards; the words-driven starter set), `grade-1`, `pictograph`, `indicative`, `compound`. Stacks will filter on tags. |
| `strokes` | Stroke count; must match `strokes/<char>.json`. |
| `radical`, `radicalNumber` | The key (radical) and its classical number (1–214). |
| `phonetic` | Optional; the phonetic component, only if there is one. |
| `onyomi`, `kunyomi` | Lists in kana; kunyomi uses `.` before okurigana and `-` for affixes. |
| `distractors` | Optional kanji used as wrong options in the quiz; each must have a card. |

## Word article

| Field | Meaning |
| --- | --- |
| `word` | The word as written; must equal the file name. |
| `reading` | Kana reading. |
| `title` | Short English gloss. |
| `type` | `kango`, `wago`, `jukujikun` or `gairaigo`. Mixed on+kun words (e.g. 円高 えんだか) have no type of their own: use `kango` for an on-first compound and say in the body that it is mixed (jūbakoyomi). |
| `kanji` | Kanji occurring in the word. |
| `tags` | Free tags. |

Body: meaning and usage, how the kanji combine, synonyms and antonyms, and the distinctive nuance.

## Strokes file

```json
{ "schemaVersion": 1, "kanji": "休", "source": "KanjiVG ...", "sourceRevision": "<commit>",
  "viewBox": [0, 0, 109, 109], "strokeCount": 6,
  "strokes": [ { "id": 1, "type": "㇒", "points": [[x, y], ...] } ] }
```

Strokes are listed in stroke order; each stroke is 16 points sampled by arc length from the KanjiVG path.

## Links and safety

- Links between files are relative `.md` paths (`../words/大小.md`) so they also work on GitHub. The app turns them into in-app navigation with a back button.
- Other links must be `https://`. Raw HTML is not allowed. Text that names a kanji or word without a card is left as plain text.
- Review state in the app is keyed by the kanji character, so don't rename cards; change `title` and body freely.

## Tools

```
pip install pyyaml svgpathtools
python tools/generate_strokes.py     # creates missing strokes/*.json
python tools/validate.py             # checks front matter, links, stroke counts
python tools/build_manifest.py       # refreshes manifest.json
```
