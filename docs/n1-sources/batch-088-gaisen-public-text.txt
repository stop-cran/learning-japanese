「凱旋」の意味・読み・例文・類語
がい‐せん【×凱旋】
［名］(スル)《「凱」は戦勝のときに奏する音楽、「旋」は帰る意》戦いに勝って帰ること。凱陣。凱帰。「故国に凱旋する」
[補説]スポーツの国際大会などで勝って帰ることや、成功を収めて帰ることにも用いられる。「凱旋パレード」「凱旋公演」
[類語]勝つ・打ち勝つ・競り勝つ・打ちのめす・打倒・勝利・戦勝・制覇・凱歌を揚げる・軍配を上げる

「凱旋」の意味・読み・例文・類語
がい‐せん【凱旋】
〘 名詞 〙 ( 「凱」は戦いに勝った時奏する音楽、転じてかちどき、「旋」は帰ること ) 勝利を祝う歌をうたって帰ること。戦いに勝って帰ること。凱陣。凱還。〔令義解（718）〕[初出の実例]「安倍貞任奥州をみだりしを、源頼義朝臣十二年までにたたかひ、凱旋(ガイセン)の日、正四位下に叙し」(出典：神皇正統記（1339‐43）下)[その他の文献]〔謝霊運‐撰征賦〕
