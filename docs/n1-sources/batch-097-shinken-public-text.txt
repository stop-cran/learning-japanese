「真剣」の意味・読み・例文・類語
しん‐けん【真剣】
［名］本物の刀剣。木刀や竹刀しないに対していう。
［形動］［文］［ナリ］まじめに物事に対するさま。本気で物事に取り組むさま。「将来を真剣に考える」「真剣なまなざし」
[派生]しんけんさ［名］しんけんみ［名］

「真剣」の意味・読み・例文・類語
しん‐けん【真剣】
〘 名詞 〙① ほんものの刀剣。本身(ほんみ)。木刀(ぼくとう)、竹刀(しない)などに対していう語。[初出の実例]「真剣(シンケン)では、拙者得いたすまいとおぼすか」(出典：浮世草子・武道伝来記（1687）三)[その他の文献]〔通典注〕② ( 形動 ) 本気であること。まじめであること。また、そのさま。[初出の実例]「山吹色の真剣(シンケン)の商ひ」(出典：浮世草子・好色敗毒散（1703）三)「これから真剣(シンケン)でお話しを」(出典：歌舞伎・敵討天下茶屋聚（1832）二)③ ( 形動 ) 真実であること。うそ、いつわりでないこと。また、そのさま。[初出の実例]「『ヱヱうそじゃ』『しんけん』」(出典：洒落本・睟のすじ書（1794）壱貫目つかひ)
