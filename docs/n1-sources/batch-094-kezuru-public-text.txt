［動ラ五（四）］
１ 刃物で物の表面を薄く切り取る。そぐ。「鉛筆を―・る」
２ 一部分を取り除いて全体の量を減らす。削減する。「予算を―・る」「人員を―・る」
３ 全体からその部分を取り除く。削除する。「文章を―・って短くする」「名簿から名前を―・る」
４ 《大工仲間の語から。「板をけずる」の略という》酒を飲む。
「甚五郎左がきいて―・るなり」〈柳多留・五五〉

「削る」の意味・読み・例文・類語
けず・るけづる【削・梳】
〘 他動詞 ラ行五（四） 〙[ 一 ] ( 削 )① 刃物などで、表面を薄くそぎ取る。少しずつへぎ取る。[初出の実例]「斉しくあらずは、剗(ケツリ)て斉平にあらしむべし」(出典：四分律行事鈔平安初期点（850頃）)「いとらうたげに、白くそびやかに、柳をけづりて、作りたらむやうなり」(出典：源氏物語（1001‐14頃）横笛)② 付いていた官位、名目などを取り除く。また、ある物の一部分を取り除く。削減する。削除する。[初出の実例]「共坐二此事一、解レ官削レ爵」(出典：日本三代実録‐貞観五年（863）五月一日)③ そしる。けなす。誹謗(ひぼう)する。[初出の実例]「ぼっとりとして他宗をば、けづりけづりてけんくゎずき、あらじゃうごわの日蓮坊」(出典：仮名草子・ぬれぼとけ（1671）上)④ ( 江戸時代、大工仲間の語から出たという ) 酒を飲む。〔談義本・教訓不弁舌（1754）〕⑤ 江戸時代、芝居関係者の間で、値ぎることをいう。〔南水漫遊拾遺（1820頃）〕[ 二 ] ( 梳 ) 櫛(くし)で髪筋をすきとおす。髪をとかす。くしけずる。[初出の実例]「朝寝髪吾は梳(けづら)じ愛(うつくし)き君が手枕(たまくら)触れてしものを」(出典：万葉集（８Ｃ後）一一・二五七八)
はつ・る【削・剥・脱】
[ 1 ] 〘 他動詞 ラ行四段活用 〙① 皮などをはぐ。そぎ落とす。へずる。[初出の実例]「剥皮 上波川流(ハツル)」(出典：新訳華厳経音義私記（794）)「切てなり共、はつってなり共とらせられい」(出典：雲形本狂言・地蔵舞（室町末‐近世初）)② 口銭をとる。上前をはねる。[ 2 ] 〘 自動詞 ラ行四段活用 〙 ( 脱 ) ぬけ落ちる、外れる意か。[初出の実例]「枯れたる松に登り、脱(ハツリ)て落ち死にき〈国会図書館本訓釈 松脱 ハツリキ〉」(出典：日本霊異記（810‐824）中)
