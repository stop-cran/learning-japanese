# 用いる (もちいる) - use; make use of

## Meaning

用いる is a transitive ichidan verb meaning "use; employ; make use of." The tool, material, or method used takes を. Useful forms are 用います, 用いて, and 用いた.

- 説明には図を用います。 (せつめいにはずをもちいます。) - I use diagrams in the explanation.
- この研究では新しい方法を用いました。 (このけんきゅうではあたらしいほうほうをもちいました。) - We used a new method in this research.

Both examples concern selecting something as a means for a purpose, not merely owning it.

## How the kanji combine

[用](../kanji/用.md) contributes use or application. It writes もち- in this verb, with いる as okurigana. The complete reading is もちいる, including both the ち and the following い; it is not もいる.

## Synonyms and antonyms

[使う](使う.md) (つかう) overlaps broadly with 用いる and is useful in everyday requests. 用いる fits descriptions of methods and materials, including explanatory prose. This is a difference in typical context, not a prohibition on speaking the word.

## Distinctive meaning

The English gloss "employ" here need not mean hiring a worker: one can employ a method. 用いて is useful for linking the means to another action, as in 図を用いて説明する (ずをもちいてせつめいする), "explain using diagrams." The object is still marked with を.
