# 変化 (へんか) — change; transformation

## Meaning

変化 names a change in state, appearance, or condition. With する it describes something changing:
the changing thing takes が, rather than being an object acted on with を.

- 葉の色が変化しました。 (はのいろがへんかしました。) — The leaves' color changed.

As a noun, it also fits 変化に気づく (へんかにきづく), "notice a change."
Nothing in 変化 alone says whether the change is desirable.

## How the kanji combine

[変](../kanji/変.md) contributes change or alteration; [化](../kanji/化.md) contributes transformation.
The two meanings reinforce a shift from one state to another. The on readings are ヘン + カ.

## Synonyms and antonyms

変わる (かわる) is a native verb for changing. 色が変わる (いろがかわる), "the color changes,"
can describe the same process as 色が変化する.

[変更](変更.md) (へんこう) is useful for revising something: 予定を変更する
(よていをへんこうする), "change the plan." Notice the object marked with を.
This is not the same construction as a state changing with が変化する.

## Distinctive meaning

変化 can name the process or the difference observed afterward. It need not be dramatic, sudden, or intentional.
To describe actively making something change with this word, use a causative form such as 変化させる,
not simply an object followed by を変化する.
