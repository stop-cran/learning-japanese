# 弥縫策 (びほうさく) — stopgap measure; makeshift fix

## Meaning

弥縫策 is a measure that covers up a problem for the time being so that things can get by, without dealing with its cause.

- 値上げを先に延ばすのは、ただの弥縫策にすぎない。 (ねあげをさきにのばすのは、ただの びほうさくにすぎない。) — Putting off the price rise is nothing more than a stopgap measure.
- 市は弥縫策を講じるだけで、根本的な対策を取らなかった。 (しはびほうさくをこうじるだけで、こんぽんてきなたいさくをとらなかった。) — The city only took stopgap measures and never dealt with the root cause.

## How the kanji combine

[弥](../kanji/弥.md) (び) and [縫](../kanji/縫.md) (ほう) form 弥縫 (びほう), “patching up”; 縫 means to sew. [策](../kanji/策.md) (さく) means a plan or measure, so a 弥縫策 is a plan that only patches things up.

## Synonyms and antonyms

[対策](対策.md) (たいさく) is any countermeasure. 弥縫策 is one judged to be only temporary; the second example contrasts it with 根本的な対策, a measure that deals with the root cause.

## Distinctive meaning

Read the word びほうさく. JMdict also records びぼうさく but marks it as an irregular kana form.
