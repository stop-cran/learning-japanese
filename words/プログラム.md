# プログラム - program; event plan; computer program

## Meaning

プログラム has three connected practical uses: an event's plan or
order of activities, a printed program booklet, and a computer program
or programming.

- 今日のプログラムを確認しました。 (きょうのプログラムをかくにんしました。) - I checked today's program of events.
- 入口で演奏会のプログラムをもらいました。 (いりぐちでえんそうかいのプログラムをもらいました。) - I received a concert program at the entrance.
- データを整理するプログラムを作りました。 (データをせいりするプログラムをつくりました。) - I made a program for organizing data.

The second example names the publication, not the performance itself.
The third names computer instructions, not an event timetable.

## How the kanji combine

This katakana loanword has no kanji compound.
Learn the whole word and its context rather than deriving the meaning
from visually similar Japanese words.

## Synonyms and antonyms

[スケジュール](スケジュール.md) and [日程](日程.md) (にってい)
overlap in planned activities; [順序](順序.md) (じゅんじょ) focuses on their order.
[冊子](冊子.md) (さっし) is a booklet, not necessarily an event program.
[ソフト](ソフト.md) also abbreviates software; that sense is not the
adjective "soft."

## Distinctive meaning

[番組](番組.md) (ばんぐみ) is the usual broadcast-program word;
it is not an unrestricted replacement for a computer program or concert booklet.
[次第](次第.md) (しだい) also has an order/program use, as in
式次第 (しきしだい), an order of ceremony.
Do not assume that one English "program" always denotes the same Japanese object.
