# 零 (れい) — zero

## Meaning

零 means zero. The reading れい is useful in numbers, measurements, and decimal expressions. In ordinary numeric notation, zero is often written 0 rather than this kanji.

- 今朝は零度でした。  
  けさはれいどでした。  
  "It was zero degrees this morning."

零点五 (れいてんご) reads the decimal number 0.5; 点 (てん) marks the decimal point in that reading.

## How the kanji combine

零 is a single character using the on reading れい. The dictionary also recognizes ０ and 〇 for this zero word. These are written forms, not extra syllables added to the reading.

## Synonyms and antonyms

ゼロ also means zero and is common in speech. まる, literally "circle", can read a zero in some digit-by-digit identifiers, but is not a replacement in every mathematical expression.

## Distinctive meaning

Keep the reading tied to the context: れいてんご is a decimal reading, whereas a telephone number is read digit by digit. Zero has no useful lexical antonym; other numbers are values, not opposites in the vocabulary sense.
