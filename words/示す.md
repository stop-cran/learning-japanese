# 示す (しめす) — show; indicate

## Meaning

示す makes something apparent: it can show a route, demonstrate an idea, or express an attitude.
It is transitive, meaning that the thing shown is an object marked with を.
The subject can be a person, a sign, or information that points to a conclusion.

- この矢印は出口を示しています。 (このやじるしはでぐちをしめしています。) — This arrow indicates the exit.
- 先生は例を示しました。 (せんせいはれいをしめしました。) — The teacher presented an example.

It is a godan verb, whose ending changes before other forms: 示します (しめします), 示した (しめした).

## How the kanji combine

[示](../kanji/示.md) supplies the idea of showing or indicating.
す is the written verb ending; 示す is one native Japanese verb, not a two-word compound.
Before ます, use 示し: 示します.

## Synonyms and antonyms

見せる (みせる) also means "show." It works naturally when letting someone see something:
写真を見せる (しゃしんをみせる), "show a photograph."
示す is useful when the focus is what something indicates or demonstrates, as with the arrow above.
The meanings overlap; this is not a rule that 示す can never involve a visible object.

指示 (しじ), "instructions; directions," contains the same kanji but is a noun that can combine with する.
It is not simply a more polite conjugation of 示す.

## Distinctive meaning

To 示す something is to make it apparent, not necessarily to cause someone to understand or agree.
An arrow can indicate the exit even if a visitor fails to notice it.
This makes "indicate" a better translation than "teach" in the first example.
