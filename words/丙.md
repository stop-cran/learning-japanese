# 丙 (へい) — third rank; class C

## Meaning

丙 is the third label after 甲 (こう) and 乙 (おつ), comparable to C after
A and B. It can identify a third rank or class in a system using these labels.
It is not the ordinary numeral for a quantity of three.

- 甲、乙、丙の順です。 (こう、おつ、へいのじゅんです。) — The order is A, B, C.
- この表では、丙は三番目です。 (このひょうでは、へいはさんばんめです。) — In this table, C is third.

These examples describe a label sequence. They do not establish any particular
school's grading rules.

## How the kanji combine

The single character [丙](../kanji/丙.md) uses the on reading ヘイ here.
There is no multi-character compound to divide. The extended sequence
甲乙丙丁 (こうおつへいてい) means A, B, C, D.

## Synonyms and antonyms

甲 (こう) and 乙 (おつ) are preceding labels, not synonyms or antonyms.
[三](三.md) (さん), "three," is a quantity rather than this class label.
丙 does not mean any rank whatsoever: it identifies the third position
in the relevant sequence.

## Distinctive meaning

In ranked evaluation, 丙 can suggest a below-standard result; that nuance
does not apply automatically to every use of a third label.

The same spelling also names the third heavenly stem in the traditional
calendar, especially read ひのえ. That calendar name appears in
[丙午](丙午.md) (ひのえうま), "Fire Horse." Do not read the rank-label examples
above as ひのえ merely because the spelling is the same.
