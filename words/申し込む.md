# 申し込む (もうしこむ) — apply; sign up

## Meaning

申し込む means to submit an application or request, for example to join a course or event.
An activity can be marked with に: 講座に申し込む (こうざにもうしこむ), "sign up for a course."
The polite form is 申し込みます (もうしこみます), and the past form is 申し込んだ (もうしこんだ).

- 日本語の講座に申し込みました。 (にほんごのこうざにもうしこみました。) — I signed up for a Japanese course.
- インターネットで申し込めます。 (インターネットでもうしこめます。) — You can apply online.

The dictionary classifies this as a transitive verb, but the thing joined is not automatically an を-object; learn the construction with the activity.

## How the kanji combine

[申](../kanji/申.md) appears in 申し, the connecting stem of 申す (もうす), "say" in humble speech.
[込](../kanji/込.md) appears in 込む (こむ), which can add an inward or thorough-action sense after a verb stem.
The whole compound means to put in a request or application. Both parts use native readings, so this is wago rather than kango.

## Synonyms and antonyms

申請 (しんせい) also means an application or request; 申請する is useful for requesting approval or permission.
The words overlap, but an expression used for one application procedure is not automatically the preferred wording for another.
There is no single opposite covering both signing up and the word's other request uses.

## Distinctive meaning

申し込む describes making the request, not a guarantee that it is accepted.
Its 申 does not make it a substitute for 申す in a self-introduction: 田中と申します (たなかともうします) means "My name is Tanaka,"
whereas 申し込む needs an application or request context.
