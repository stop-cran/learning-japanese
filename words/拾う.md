# 拾う (ひろう) — pick up; gather

## Meaning

拾う means to pick something up, often from the ground, or gather scattered things. It can include finding an object someone has dropped. The object takes を.

- 道で鍵を拾いました。  
  みちでかぎをひろいました。  
  "I found and picked up some keys on the road."
- 公園でごみを拾います。  
  こうえんでごみをひろいます。  
  "I pick up litter in the park."

## How the kanji combine

拾 supplies the native reading ひろ, followed by う. It is godan: 拾います (ひろいます), 拾って (ひろって), 拾わない (ひろわない). Notice わ in the negative, not あ.

## Synonyms and antonyms

集める (あつめる), "collect; gather", is broader and need not involve picking things off a surface. [落とす](落す.md) (おとす), "drop", is a useful contrast for a physical object.

## Distinctive meaning

拾う is not the general verb for taking any object. 拾った鍵 (ひろったかぎ), "keys I found and picked up", suggests found objects rather than simply taking one's own keys from a shelf. Other uses exist, but context must support them.
