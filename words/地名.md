# 地名 (ちめい) - place name

## Meaning

地名 is the name of a place, such as a town, region, or geographical
feature. The technical English word "toponym" means a place name.

- この地名の読み方を教えてください。 (このちめいのよみかたをおしえてください。) - Please tell me how to read this place name.
- 古い地図で、この地名を見つけました。 (ふるいちずで、このちめいをみつけました。) - I found this place name on an old map.

It is a noun. 地名の由来 (ちめいのゆらい) means
"the origin of a place name."

## How the kanji combine

[地](../kanji/地.md) identifies a place, and [名](../kanji/名.md)
its name: a modifier-plus-head relationship. Read チ + メイ,
not the standalone native reading な for the second character.

## Synonyms and antonyms

[名前](名前.md) (なまえ) is a name more generally.
町の名前 (まちのなまえ), "a town's name," can identify a 地名.
[氏名](氏名.md) (しめい) concerns a person's full name instead.

## Distinctive meaning

地名 names the place's designation, not the place itself or its entire
postal address. 地名の読み方 asks how to pronounce the name;
it is not asking for directions to the location. Place-name readings
can be special, so check the established reading of each name rather
than assembling it mechanically from familiar character readings.
