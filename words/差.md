# 差 (さ) — difference; gap

## Meaning

差 is a difference between things, often a gap whose size matters.
Use AとBの差 for "the difference between A and B," or 差がある (さがある) for "there is a difference."

- 二人の身長には差があります。 (ふたりのしんちょうにはさがあります。) — There is a difference in height between the two people.
- 値段の差は百円です。 (ねだんのさはひゃくえんです。) — The price difference is one hundred yen.

## How the kanji combine

There is only one kanji, [差](../kanji/差.md), read with the on reading サ.
It functions as a noun by itself and also as a final element in other words.
For example, 時差 (じさ), "time difference," specifies the area in which the difference occurs.

## Synonyms and antonyms

違い (ちがい) also means "difference" and can draw attention to how things differ.
差 is particularly useful when stating the size of a gap, as in the price example.
This is a useful focus, not a ban on using either word in other kinds of comparison.
差がない (さがない), "there is no difference," directly negates the comparison.

## Distinctive meaning

A 差 does not by itself tell you which side is better.
A height difference is a measurable contrast, not automatically an advantage or a fault.
Add the relevant quantity or context rather than assuming that "difference" means a problem.
