# 正門 (せいもん) - main gate

## Meaning

正門 is the main or front gate of a school, temple, estate or similar grounds.
It is a noun. 正門の前で means in front of the main gate.

- 学校の正門の前で会いましょう。 (がっこうのせいもんのまえであいましょう。) - Let's meet in front of the school's main gate.
- 工事中は正門を使えません。 (こうじちゅうはせいもんをつかえません。) - The main gate cannot be used during construction.

前で marks the location of meeting; を marks the gate used.

## How the kanji combine

[正](../kanji/正.md) contributes principal or main here, and [門](../kanji/門.md)
contributes gate. The first part specifies which gate is meant, rather than
calling a physically straight gate correct. Read セイ + モン.

## Synonyms and antonyms

[門](門.md) (もん) is gate generally; [入口](入口.md) (いりぐち) is an entrance.
[玄関](玄関.md) (げんかん) concerns a building's entrance or entryway.
A main gate may serve as an entrance, but these words do not identify exactly
the same structure in every setting. 裏門 (うらもん), back gate, is a useful contrast.

## Distinctive meaning

Learn the actual meeting place: the 正門 can be some distance from the building's
front door or reception area. Main gate does not mean the biggest gate by definition,
and an entrance to an individual room is not automatically a 正門.
