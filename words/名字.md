# 名字 (みょうじ) -- family name; surname

## Meaning

名字 is a family name or surname. 苗字 is another spelling of the same
みょうじ. English "last name" can translate it, but does not describe
its position in ordinary Japanese family-name-first ordering.

- 私の名字は田中です。 (わたしのみょうじはたなかです。) -- My family name is Tanaka.
- 名字と名前を別々に書いてください。 (みょうじとなまえをべつべつにかいてください。) -- Please write your family name and given name separately.

In the second sentence 名前 is understood as the given name because it
is contrasted with 名字; 名前 alone is not restricted to that meaning.

## How the kanji combine

[名](../kanji/名.md) concerns a name and [字](../kanji/字.md) a written
character or name. Learn ミョウ + ジ as this compound's reading;
名字 is not read なじ by combining arbitrary familiar readings.

## Synonyms and antonyms

- [姓](姓.md) (せい) directly overlaps in surname or family name.
- [名前](名前.md) (なまえ) is broader: a name, or a given name in an appropriate contrast.
- [氏名](氏名.md) (しめい) means the full name, not just the surname.
- [氏](氏.md) (し) on the existing suffix card is a respectful name suffix, not an unrestricted replacement for 名字.

## Distinctive meaning

Keep spelling, reading and name order separate. 苗字 and 名字 are not
the family and given halves of a name; both write みょうじ. Likewise,
the generic term 名字 is not the proper name 田中 (たなか).
