# 乙種 (おつしゅ) — B grade; second class

## Meaning

乙種 is a noun for the second class when things are sorted with the labels 甲, 乙 and 丙, like A, B and C. JMdict glosses it as "B-grade; second-class" and refers to 甲乙丙 (こうおつへい), "A, B and C; first, second and third." Digital Daijisen defines it as the second item when things are classified as 甲, 乙, 丙 and so on: 第2種, the second class.

- この資格は、甲種、乙種、丙種に分かれている。
  (このしかくは、こうしゅ、おつしゅ、へいしゅにわかれている。)
  "This qualification is divided into class A, class B and class C."
- 姉は乙種の試験に合格した。
  (あねはおつしゅのしけんにごうかくした。)
  "My older sister passed the class B exam."

These are original usage examples, not quotations from a dictionary or other source.

## How the kanji combine

[乙](../kanji/乙.md) (オツ) contributes second place in a ranking; Digital Daijisen gives 乙種 as its example for this sense of 乙. [種](../kanji/種.md) (シュ) contributes a kind or class: things grouped by a shared property. This is a modifier + head relation: the class that comes second. It explains the compound's meaning, not the historical origin of either character.

## Synonyms and antonyms

甲種 (こうしゅ), "A-grade; first-class," names the class before 乙種, and 丙種 (へいしゅ), "third grade; third class; C-grade," the class after it. [丙](丙.md) (へい), "third rank; class C," is the third label alone. [級](級.md) (きゅう), "class; rank; level," is a general word for any class or rank.

None of these is a synonym, and there is no single fixed antonym.

## Distinctive meaning

乙 on its own, read おつ, can also mean stylish or chic; neither JMdict nor Digital Daijisen gives that sense for 乙種. Digital Daijisen's second sense of 乙種 is a short form of 乙種合格 (おつしゅごうかく), which it describes as formerly the pass rank after 甲種 in the conscription examination (徴兵検査).
