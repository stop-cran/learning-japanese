# コード (コード) - code; cord; musical chord

## Meaning

コード covers three separate lexical identities with the same written form and pronunciation. All are nouns, but their contexts differ.

- **Code**: このコードを修正しました。 (このコードをしゅうせいしました。) - I corrected this code. In computing it refers to program code.
- **Cord**: 電源のコードが短すぎます。 (でんげんのコードがみじかすぎます。) - The power cord is too short. This is a physical cable, not software.
- **Chord**: ギターで三つのコードを弾きました。 (ギターでみっつのコードをひきました。) - I played three chords on the guitar.

The code identity can also concern rules or a set of symbols. That is polysemy within the code entry; cord and musical chord have their own dictionary entries.

## How the kanji combine

The katakana spelling has no kanji components. The long-vowel mark ー belongs to the word. English distinguishes "code," "cord," and "chord" in writing; Japanese コード leaves that distinction to context.

## Synonyms and antonyms

[紐](紐.md) (ひも) is a string or cord in a broader physical sense, not computer code. 和音 (わおん) is a useful comparison for a musical chord. Neither is an antonym.

## Distinctive meaning

Do not combine the source's three glosses into one undifferentiated definition. "Write code," "a short power cord," and "play a chord" identify different things. This shared article covers the source mixture without assigning each identity an independently sourced JLPT level.
