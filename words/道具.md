# 道具 (どうぐ) — tool; implement

## Meaning

道具 is an implement used to do something: a tool, utensil, or piece of apparatus.
Use an activity to identify its purpose, as in 料理に使う道具 (りょうりにつかうどうぐ),
"tools used for cooking." The word can refer to one implement or equipment collectively; context supplies the number.

- この道具の使い方を教えてください。 (このどうぐのつかいかたをおしえてください。) — Please show me how to use this tool.
- 料理に使う道具を洗いました。 (りょうりにつかうどうぐをあらいました。) — I washed the cooking utensils.

## How the kanji combine

[道](../kanji/道.md) can suggest a way or course, and [具](../kanji/具.md) contributes an implement.
"An implement for carrying out a task" is a useful semantic association.
The established compound does not mean only a tool used on a road.
Its on readings are ドウ + グ.

## Synonyms and antonyms

物 もの means a thing or object, a wider category that need not be used as a tool.
家具 かぐ means furniture. It shares 具 but does not name every kind of equipment.
There is no general-purpose antonym for 道具; identify the relevant kind of object instead.

## Distinctive meaning

道具 highlights an object's use in an activity, not its material or complexity.
A simple kitchen utensil can be 道具 just as a more elaborate implement can.
In the first example, the speaker wants instructions for using it, not merely its name.
