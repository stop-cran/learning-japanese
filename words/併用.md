# 併用 (へいよう) — combined use; using together

## Meaning

併用 means using two or more things together. It can describe using methods, tools or medicines together.

- この薬は、ほかの薬と併用しないでください。 (このくすりは、ほかのくすりとへいようしないでください。) — Do not use this medicine together with other medicines.
- この方法は、別の方法と併用できます。 (このほうほうは、べつのほうほうとへいようできます。) — This method can be used together with another method.

These are original usage examples, not dictionary quotations.

## How the kanji combine

[併](../kanji/併.md) means joining things together, and [用](../kanji/用.md) means use. The word is read へいよう.

## Synonyms and antonyms

併用 means using things together; it does not say whether they are mixed into one thing.

## Distinctive meaning

JMdict glosses 併用 as combined use, using jointly or using at the same time.
