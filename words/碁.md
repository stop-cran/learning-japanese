# 碁 (ご) - go board game

## Meaning

碁 is go, the board game played with black and white stones.
It is a noun. 碁を打つ (ごをうつ) means "play go";
打つ is the conventional verb in this expression.

- 祖父は毎日、友達と碁を打ちます。 (そふはまいにち、ともだちとごをうちます。) - My grandfather plays go with his friends every day.
- 昨日から碁を習い始めました。 (きのうからごをならいはじめました。) - I started learning go yesterday.

The noun names the game; it does not by itself name a particular player,
move, or individual stone.

## How the kanji combine

This single-character word uses the on reading ゴ.
碁 supplies the game meaning; no second character needs to be inferred.
JMdict also records the spellings 棊 and 棋 for this entry.
Their presence does not make all compounds containing 棋 refer to go.

## Synonyms and antonyms

囲碁 (いご) is another name for the same game.
[五](五.md) (ご), five, and [語](語.md) (ご), language or word, have
the same reading but unrelated meanings.
将棋 (しょうぎ), shogi, is a different board game.

## Distinctive meaning

English "go" also names a movement verb, but that meaning does not
belong to Japanese 碁. Learn the spelling and game together rather
than using the sound ご as a translation of English "go."
