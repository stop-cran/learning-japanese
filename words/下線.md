# 下線 (かせん) - underline; underscore

## Meaning

下線 is a line beneath writing, used to mark or emphasize it. 下線を引く (かせんをひく) means drawing an underline.

- 大切な言葉に下線を引いてください。 (たいせつなことばにかせんをひいてください。) - Please underline the important words.
- 下線のある部分を読んでください。 (かせんのあるぶぶんをよんでください。) - Please read the underlined part.

下線部 (かせんぶ) is the underlined portion, a useful term in exercise instructions.

## How the kanji combine

[下](../kanji/下.md) specifies the position below; [線](../kanji/線.md) supplies the line. The first character modifies the second. Their on readings combine as カ + セン, not the native した reading of 下.

## Synonyms and antonyms

[線](線.md) (せん) is a line more generally. アンダースコア names an underscore, including the low-line character used in computer text. Distinguish a mark beneath a whole passage from a particular typed character when the task requires it.

## Distinctive meaning

下線 is a noun. In ordinary writing instructions, say 下線を引く rather than treating it as an English verb by itself. An underline identifies text; it is not the text's meaning or an instruction to delete it.
