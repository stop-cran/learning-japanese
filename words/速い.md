# 速い (はやい) — fast

## Meaning

速い describes speed: movement or an action takes little time. It is an い-adjective, so it directly modifies a noun:
速い電車 (はやいでんしゃ), "a fast train." To describe how an action is done, use 速く (はやく).

- この電車は速いです。 (このでんしゃははやいです。) — This train is fast.
- もっと速く走れますか。 (もっとはやくはしれますか。) — Can you run faster?

## How the kanji combine

[速](../kanji/速.md) supplies the speed meaning. The written い completes the native adjective はやい;
this is not an on-reading compound. The negative is 速くない (はやくない), "not fast."

## Synonyms and antonyms

遅い (おそい), "slow," is the opposite in a speed comparison.
[早い](早い.md) (はやい) has the same pronunciation but supplies the "early" meaning:
早い時間 (はやいじかん), "an early time." JMdict also recognizes overlap in fast/quick uses; this is not a rule that the two spellings never overlap.

## Distinctive meaning

A train can be fast yet arrive late. 速い describes its speed, not its punctuality.
For the practical spelling contrast, ask whether you mean "at an early time" or "at high speed."
