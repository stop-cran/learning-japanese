# ワープロ (ワープロ) - word processor

## Meaning

ワープロ means a word processor. Depending on context, it can refer to a dedicated document-writing machine or word-processing software.

- 昔、父はワープロで手紙を書いていました。 (むかし、ちちはワープロでてがみをかいていました。) - My father used to write letters on a word processor.
- このパソコンにはワープロソフトが入っています。 (このパソコンにはワープロソフトがはいっています。) - This computer has word-processing software installed.

で marks the tool used for writing. ワープロソフト makes the software meaning explicit.

## How the kanji combine

The word shortens ワードプロセッサー, from English "word processor," by retaining parts of both words. Keep the long vowel in ワー. This is katakana word formation, not kanji composition.

## Synonyms and antonyms

[パソコン](パソコン.md) is a personal computer, a more general-purpose machine. A テキストエディター is a text editor; it need not have the document-layout functions of a word processor.

## Distinctive meaning

In accounts of older office equipment, ワープロ often means a dedicated machine rather than today's computer application. It is not simply another name for every computer. Context or the compound ワープロソフト clarifies which object is meant.
