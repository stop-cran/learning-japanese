# 郡 (ぐん) - county; district

## Meaning

郡 names a district or county. In modern Japanese addresses, it is a geographical grouping of towns and villages within a prefecture.
It is not itself a modern county government, and a city is not a subdivision of a 郡.

- この村はどの郡にありますか。 (このむらはどのぐんにありますか。) - Which district is this village in?
- 住所の郡名を確認しました。 (じゅうしょのぐんめいをかくにんしました。) - I checked the district name in the address.

English "county" is useful in translation, but do not assume that every country's counties have the same administrative structure.

## How the kanji combine

This is a single-character Sino-Japanese noun, using the on reading グン.
The selected modern county/district sense is read ぐん.
Dictionary historical uses also include the reading こおり; that is not a free replacement in a modern address.

## Synonyms and antonyms

[地区](地区.md) (ちく) and [地域](地域.md) (ちいき) can name areas or districts without identifying this particular address unit.
[県](県.md) (けん) is a prefecture in Japanese administration, a different level.
[国](国.md) (くに), "country; nation," is not the meaning of 郡 here.

## Distinctive meaning

Read 郡 with the place name and the administrative context.
The source list's English "country" should not be learned as "nation"; the intended modern gloss is county/district.
