# 型 (かた) - mold; type; pattern

## Meaning

型 is a noun for a mold or template, a type or model, or a prescribed form. Learn the object or activity around it rather than choosing one English translation for every occurrence.

- 生地を型に入れます。 (きじをかたにいれます。) - Put the batter into the mold.
- 空手の型を練習しています。 (からてのかたをれんしゅうしています。) - I am practicing karate kata.

In martial arts, 型 names a set sequence of movements. In other settings it can be an established pattern: 型にはまった (かたにはまった), "formulaic; conventional."

## How the kanji combine

型 is a single kanji read with its native reading かた. It can name a pattern that shapes an object or guides an action. As a suffix for a type or model, it is read がた, as in 新型 (しんがた), "new model."

## Synonyms and antonyms

[形](形.md) (かたち) concerns shape or form. A cake has a 形, while the vessel that shapes it can be its 型. [種類](種類.md) (しゅるい) describes a kind or category and overlaps with the type sense.

## Distinctive meaning

型 is not limited to a visible outline: it can organize a procedure or classify an item. Conversely, the mold in the first example is a physical object, not merely the cake's category. No single antonym covers these uses.
