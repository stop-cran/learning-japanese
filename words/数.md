# 数 (かず) — number; amount

## Meaning

数 is the number or amount of something. A useful pattern is **noun + の数**:
人の数 (ひとのかず), "the number of people."
The noun かず names the quantity; 数える (かぞえる) names the act of counting.

- 人の数が増えました。 (ひとのかずがふえました。) — The number of people increased.
- りんごの数を数えてください。 (りんごのかずをかぞえてください。) — Please count the apples.

The separate on-reading word 数 (すう) is used for numbers in mathematical discussion:
二つの数を足します (ふたつのすうをたします), "I add two numbers."
As a prefix, 数 (すう) means "several": 数日 (すうじつ), "several days,"
and 数人 (すうにん), "several people." The prefix does not specify an exact count.

## How the kanji combine

There is only one kanji: [数](../kanji/数.md) supplies the meaning "number."
かず is its native Japanese reading, so this noun is wago, not an on-reading compound.
The same character has スウ in [数学](数学.md) (すうがく), "mathematics."
The added すう uses do not replace this article's primary reading かず.

## Synonyms and antonyms

[数字](数字.md) (すうじ) can name a numeral or digit, such as the written symbol 3.
[番号](番号.md) (ばんごう) is a number used as a label or identifying series of digits:
a room number is not a count of the rooms.
量 (りょう) emphasizes quantity or volume, useful for something measured rather than counted item by item.

## Distinctive meaning

English "number" covers both how many and which identifying number. 数 is especially useful for the
first question: 部屋の数 (へやのかず) asks about the number of rooms, not a particular room's label.
For "many" or "few," describe the count with 数が多い (かずがおおい) or 数が少ない (かずがすくない);
数 itself does not say whether the quantity is large.
