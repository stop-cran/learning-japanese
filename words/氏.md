# 氏 (し) - respectful name suffix

## Meaning

氏 (し) is a respectful suffix attached directly to a person's name, as in 田中氏 (たなかし).
English may translate it as Mr., Ms., or a similar title, or omit the title when natural.
It does not itself specify marital status.

- 田中氏は会議に出席しました。 (たなかしはかいぎにしゅっせきしました。) - Mr./Ms. Tanaka attended the meeting.
- これは山田氏の意見です。 (これはやまだしのいけんです。) - This is Mr./Ms. Yamada's opinion.

The suffix forms part of the name expression: attach は or の after it, not between the name and 氏.

氏 (し) can also mean **clan**. In a historical clan name such as **藤原氏** (ふじわらし), "the Fujiwara clan," it identifies the lineage group rather than addressing one person as Mr. or Ms. Fujiwara.

## How the kanji combine

氏 is a single character read シ in this suffix.
The same character read **うじ** is a separate dictionary identity meaning family name, lineage, or birth.
Sharing the character does not make those definitions the ordinary meaning of the name suffix し.
However, the clan meaning above is also recorded under し; lineage-related uses are not confined to the reading うじ.

## Synonyms and antonyms

さん is another respectful name suffix and is useful in everyday address.
氏 fits reference to named people in reports and other relatively formal descriptions; it is not a default replacement for さん when calling to a friend.
[名前](名前.md) (なまえ) is the name itself, not a respectful suffix.

## Distinctive meaning

Read the complete expression and context: 田中氏 in the examples identifies a person respectfully, while 藤原氏 in a historical discussion can identify a clan.
The dictionary's respectful label does not impose an absolute rule about the speaker's gender.
Do not add both 氏 and さん mechanically to the same name.
